Getting Started

Prerequisites & Installation
  1. Node.js and NPM : You need Node.js installed on your machine. We recommend the latest LTS version. Download from nodejs.org.
  2. Installation : Open your terminal in the project root directory (dentia-next) and run the following command to install dependencies:
    npm install
    or if you use Yarn:
    yarn install
  3. Development Server : Run the following command to start the local development server:
    npm run dev
    Navigate to http://localhost:3000 to view the app.
  4. Production Build : This project is configured for static export (`output: 'export'`). To build for production:
    npm run build
    The static files will be generated in the out/ directory, ready to be deployed to any static hosting service (Netlify, Vercel, GitHub Pages, etc.).

Customization Guide

1. Navigation Menu

The main menu is located in components/Header.tsx. To add or modify menu items:

  • Open components/Header.tsx
  • Locate the <ul id="mainmenu"> section.
  • You can add or edit <Link> components for internal navigation.

2. Preloader

The preloader component is located at components/Preloader.tsx.

  • Styles for the preloader can be found in public/css/style.css.

3. Changing Logo

To change the logo, update the image paths in components/Header.tsx and components/Footer.tsx:

<img className="logo-main logo" src="/images/logo-white.webp" alt="" />

Place your new logo files in the public/images/ directory.

4. Styles

Global styles are located in public/css/style.css. You can also use Tailwind utility classes directly in your components.

Booking & Contact Forms

The Booking and Contact forms are fully functional and powered by EmailJS. This allows you to receive emails directly without needing a backend server.

1. Setting up EmailJS

  1. Go to https://www.emailjs.com/ and create a free account.
  2. Add New Service: In your EmailJS dashboard, add a new Email Service (e.g., Gmail). Note the Service ID.
  3. Create Email Template: Create a new email template.
    • For Booking Form, use variables like {{name}}, {{email}}, {{phone}}, {{service}}, {{date}}, {{time}}, {{message}}.
    • For Contact Form, use variables like {{name}}, {{email}}, {{phone}}, {{message}}.
    • Note the Template ID for each.
  4. Get Public Key: Go to Account > API Keys and copy your Public Key.

2. Configuring Booking Form

Open components/BookingForm.tsx and locate the configuration section at the top:

const BOOKING_EMAILJS_SERVICE_ID = 'YOUR_SERVICE_ID';
const BOOKING_EMAILJS_TEMPLATE_ID = 'YOUR_TEMPLATE_ID';
const BOOKING_EMAILJS_PUBLIC_KEY = 'YOUR_PUBLIC_KEY';

Replace the empty strings with your actual EmailJS credentials.

3. Configuring Contact Form

Open components/ContactForm.tsx and locate the `sendEmail` function:

const SERVICE_ID = 'YOUR_SERVICE_ID';
const TEMPLATE_ID = 'YOUR_TEMPLATE_ID';
const PUBLIC_KEY = 'YOUR_PUBLIC_KEY';

Replace these placeholder values with your actual EmailJS credentials.

4. Fallback Mode

If you do not configure EmailJS, the forms will automatically fall back to opening the user's default email client (mailto) with the form details pre-filled. This ensures the forms are usable even without setup.
