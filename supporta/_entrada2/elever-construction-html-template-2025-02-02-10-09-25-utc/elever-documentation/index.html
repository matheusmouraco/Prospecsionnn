2.15. Set Default RTL (Right To Left)

You can manually set the default text direction to right-to-left by adding dir="rtl" to the body tag.
Or :-- You can pest this code bottom of main.js file
window.onload = function () {
document.body.setAttribute("dir", "rtl");
